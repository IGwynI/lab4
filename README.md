# Ложкин Андрей КМБ2 Лабораторная №4

# Задание 1

## Задача 1

### Текст задачи

Дерево содержит строки. Заменить в каждой строке последний символ на
заданный.

### Алгоритм решения

Ввод количества элементов дерева; 
Генерация списка из случайных строк длиной от 3 до 9 символов и преобразование его в бинарное дерево; 
Вывод исходного дерева; 
Ввод символа для замены; 
Создание нового дерева: 
Для пустого дерева возвращается Nil.
Для узла создаётся новый узел с преобразованным значением и рекурсивно обработанными левым и правым поддеревьями.
В качестве преобразования используется частично применённая функция replaceLastChar, которая заменяет последний символ строки на заданный.
Если строка пуста или равна null, она возвращается без изменений, иначе отбрасывается последний символ и добавляется новый.
Результат newTree – дерево той же структуры, но с изменёнными строками; 
Вывод результата;

# Задание 2

## Задача 1

### Текст задачи

Найти сумму четных значений, находящихся в листьях (узел является листом,
если у него нет ни левого, ни правого поддерева).

### Алгоритм решения

Ввод количества элементов дерева; 
Генерация списка из случаных чисел от -100 до 100 и создание из него бинарного дерева; 
Вывод исходного дерева; 
Вычисление суммы четных листьев. 
Функция foldTree отвечает за свертку дерева.
fNode — функция, обрабатывающая узел: вычисляет сумму поддеревьев, определяет является ли узел листом, если узел лист и его значение четное то добавляет его к sum, иначе оставляет sum.
После завершения свёртки всего дерева получаем пару (result, _). Первый элемент result — искомая сумма.
Вывод результата;
